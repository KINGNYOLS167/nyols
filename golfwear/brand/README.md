# GOLFWEAR logo kit

A **G** drawn as a ring, with a flag on the pin flying out through its opening, set beside a
widely spaced wordmark. Start with `golfwear-brand-guide.png`: it shows every version, the
colours, sizes, placement on sleeves and polos, and what not to do.

`concepts.png` shows the three directions that were explored. This kit is direction 1, "Pin".

## Which file to use

| Where | File |
|---|---|
| Tokopedia profile picture | `tokopedia/golfwear-tokopedia-avatar-1000.png` |
| Tokopedia store banner | `tokopedia/golfwear-tokopedia-banner-1200x400.png` or `-1920x480.png` (no official size was found: check Seller Center's store decoration page and ask for another size if it differs) |
| Arm sleeve print | `print/golfwear-sleeve-wordmark-120mm-black.pdf` (one colour) or `-color.pdf` |
| Polo chest, print or embroidery | `print/golfwear-chest-icon-30mm-color.pdf` (or `-black.pdf` for one thread colour) |
| Polo chest, full logo | `print/golfwear-chest-horizontal-70mm-color.pdf` |
| Website, documents, anything digital | `logo/svg/` (sharp at any size) |
| Social media, WhatsApp, photos | `logo/png/` (transparent background, 2400 px) |

The print files are vector (no pixels, no fonts) and already at the size in their name, so
CorelDRAW, Illustrator and embroidery-digitising software open them directly.

Each logo comes in four colourways:

- `color`: green, brass flag (light backgrounds)
- `reverse`: ivory, brass flag (green or dark backgrounds)
- `black`, `white`: one colour, for single-ink printing or one thread

## Colours

| Name | HEX | RGB | Use |
|---|---|---|---|
| Fairway green | `#12372A` | 18, 55, 42 | Logo, headings, backgrounds |
| Brass | `#B8975A` | 184, 151, 90 | The flag, thin lines, highlights |
| Ivory | `#F4EFE4` | 244, 239, 228 | Light backgrounds |
| Ink | `#101614` | 16, 22, 20 | Body text |

Fabric and thread shift colour: ask the printer or embroiderer to match a physical swatch.

## Type

The wordmark is drawn from **Jost** Medium (free, SIL Open Font License, on Google Fonts).
Use Jost for banners, labels and the website: Medium with wide letter spacing for headings,
Regular for text.

## Sizes

| Version | Print / embroidery | Screen |
|---|---|---|
| Mark | 12 mm print, 20 mm embroidery | 24 px |
| Horizontal logo | 35 mm wide | 120 px wide |
| Wordmark on a sleeve | 80 mm long | - |

Keep clear space of a quarter of the mark's height on every side.

## Protecting it

"Golfwear" on its own is an ordinary word for golf clothing, so it is hard to register as a
trademark. The logo (the G mark with the wordmark) is the part worth registering with DJKI.
Search the PDKI database first to check nothing similar is registered for clothing.

## Rebuilding the files

Everything here is generated by `build_logo.mjs` from one definition of the mark, the
wordmark and the colours. To change a colour or a size, edit the script and run:

```bash
npm install
```

```bash
npm run build
```

It needs Node 18+ and Playwright's Chromium (used to export PNG and PDF).
